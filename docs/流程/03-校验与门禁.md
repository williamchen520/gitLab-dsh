# 03 · 校验与门禁

## 两道校验：形状与语义

**形状校验**（现成脚本，必跑）：

```bash
python scripts/validate_arch.py --arch ARCHITECTURE.json \
  --app api:app --root ../dsh-snapshot --ignore / --ignore /chart
python scripts/validate_mcp.py
```

它回答：“契约里写的路由/工具，代码里是不是一一对应？”

**语义校验**（自己写测试，必须补）：

```text
只追加      test_inv_append_only_*
不可变      test_inv_immutable_*
状态机      test_inv_state_machine_*
幂等        test_inv_idempotent_*
预算截止    test_inv_budget_*
```

它回答：“契约承诺的行为，真的成立吗？”

> 形状对了不代表行为对。新增不变量时，**一条不变量配一条测试**。

## 文档同步校验

```bash
python scripts/render_arch_md.py --check
python scripts/render_plan_md.py plans/<plan-id>.traceability.json --check
```

两者都检查“给人看的版本”是否与 JSON 同步；不同步 → exit 1。

## 门禁清单（全过才允许提交）

```bash
python scripts/validate_arch.py ...
python scripts/validate_mcp.py
python scripts/check_traceability.py plans/<id>.traceability.json --tests-root <code-repo>
python scripts/render_arch_md.py --check
python scripts/render_plan_md.py plans/<id>.traceability.json --check
pytest -q
```

任何一条 `exit != 0`：停止提交，修复后重跑。

## 失败时允许 / 不允许

```text
允许：改代码适配契约；补测试；修 JSON（需“批准修改”）
不允许：--skip；注释掉校验；改契约参数让测试变绿；手改生成的 md
```

## 落点

```text
本地：.githooks/pre-commit 跑形状校验（快）
      .githooks/commit-msg 检查 [APPROVED_BY_HUMAN]
CI：  跑全量测试 + 追溯对账 + 文档同步（慢，但强制）
```

安装钩子：

```bash
git config core.hooksPath .githooks
```

钩子只是防误操作，`--no-verify` 可绕过；**CI 才是强制边界**。

## 一个判断标准

问自己：**“如果我现在把代码改坏一行，哪个命令会让我提交不了？”**

答不上来，说明门禁还没接上。
